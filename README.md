# Портфолио разработчика — Килин Вячеслав Александрович

Сайт-визитка fullstack-разработчика **PHP / Bitrix Framework / Битрикс24 CRM** с административной панелью для управления проектами, интеграциями и грамотами.

## Стек

- PHP 8.3
- MySQL
- JavaScript
- CSS (адаптивная вёрстка)

## Возможности

**Публичная часть**
- Главная с ФИО, должностью и акцентом на Битрикс24
- Проекты (описание, стек, скриншоты)
- Интеграции CRM: события, публичная часть, табы в карточке компании, валидация полей + примеры кода
- Раздел грамот и дипломов
- Раздел «Хобби» с текстом, обложкой и слайдером нескольких фото

**Админка** (`/admin/`)
- CRUD проектов, интеграций, хобби, грамот
- Загрузка обложек, скриншотов и галерей
- Редактирование примеров кода
- Настройки профиля и контактов
- Смена пароля

## Установка

1. Залейте файлы на хостинг с PHP 8.3+ и MySQL.
2. Убедитесь, что папки `assets/uploads` и `storage` доступны для записи.
3. Откройте в браузере `https://ваш-домен/install.php`.
4. Укажите доступ к MySQL и создайте логин/пароль администратора.
5. **Удалите `install.php`** после успешной установки.
6. Войдите в `/admin/` и заполните проекты, интеграции, грамоты, контакты.

### Важно при обновлении файлов на сервере

Рабочие доступы к MySQL хранятся в `config/database.local.php` — **не заливайте его с компьютера** и не перезаписывайте при деплое.

Если сайт снова отдал 500 после заливки — откройте `fix-database.php`, введите данные БД из панели хостинга, затем удалите этот файл.

### Альтернатива: ручной импорт SQL

Можно выполнить `sql/schema.sql` вручную (предварительно создав БД), прописать доступ в `config/database.php` и добавить админа:

```sql
INSERT INTO admins (username, password_hash, name)
VALUES ('admin', '$2y$10$...', 'Килин В.А.');
```

Хеш пароля получите через `password_hash('ваш_пароль', PASSWORD_DEFAULT)` в PHP. Затем создайте файл `storage/installed.lock`.

## Структура

```
├── admin/           # Админ-панель
├── assets/          # CSS, JS, загрузки
├── config/          # Настройки приложения и БД
├── includes/        # Ядро (DB, auth, helpers)
├── sql/             # Схема и демо-данные
├── templates/       # Шапка/подвал сайта
├── index.php        # Главная
├── projects.php     # Список проектов
├── integrations.php # Интеграции Битрикс24
├── certificates.php # Грамоты
└── install.php      # Мастер установки
```

## Безопасность

- Пароли хранятся в `password_hash`
- CSRF-токены в админ-формах
- Загрузка только изображений/PDF с проверкой MIME
- Каталоги `config`, `includes`, `sql`, `storage` закрыты через `.htaccess`
- В `assets/uploads` запрещено выполнение PHP
